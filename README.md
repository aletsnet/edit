# Procesador de Texto

Un procesador de texto simple y funcional construido con HTML, CSS y JavaScript vainilla.

## Características

- ✏️ Editor de texto enriquecido (contenteditable)
- 📤 Carga de archivos de texto (.txt)
- 💾 Descarga en múltiples formatos (TXT, PDF, DOC)
- 🎨 Herramientas de formato:
  - Negrita, cursiva, subrayado y tachado
  - Selección de fuente y tamaño
  - Alineación de texto (izquierda, centro, derecha, justificado)
  - Listas numeradas y con viñetas
  - Inserción de enlaces e imágenes
- ↶↷ Deshacer y rehacer
- 🗑️ Limpiar editor
- 🔗 Enlaces rápidos a herramientas de gramática y parafraseo

## Uso

1. Abre `index.html` en tu navegador web
2. Comienza a escribir en el área del editor
3. Usa la barra de herramientas para dar formato a tu texto
4. Sube archivos de texto usando el botón "Upload Doc"
5. Descarga tu documento en el formato deseado usando el botón "Download"

## Formatos de descarga

- **TXT**: Descarga como archivo de texto plano
- **PDF**: Descarga como HTML (abre el archivo y usa "Imprimir > Guardar como PDF" para crear un PDF)
- **DOC**: Descarga en formato compatible con Microsoft Word

## Tecnologías

- HTML5
- CSS3
- JavaScript Vanilla (sin dependencias externas)

## Compatibilidad

El editor es compatible con todos los navegadores modernos que soporten la API `contenteditable` y `document.execCommand`.
